项目要求

公司台式机、私人笔记本和家里台式机使用同一套澜汐。一次安装、配对并登记项目后，后台负责交接。日常开发路径仍是打开 IDE、编辑、运行命令，用户无需另开工作台或点击同步。

代码和会话一起到达

三端保留代码副本。已保存到磁盘的未提交修改、暂存状态、允许同步的新文件和最近可恢复的 Codex 轮次必须相互对应；绝对路径按设备映射。

人拥有最高优先级

任一设备用 VS Code 或 PyCharm 打开项目，澜汐释放该项目的自动控制。最后一个 IDE 关闭、人工 CLI 释放后，后台按原策略接回。

算力和大文件按需使用

普通开发就近执行，GPU 任务或受本机性能限制的可迁移步骤自动调度到家里。大对象默认一份持久主副本，工作缓存按需生成，重要数据另存冷备。

夜间可独立推进

项目按长期、短期或探索性管理。夜间在项目沙箱和预算内自动处理符合规则的操作审批，iPhone 可暂停、看结果和处理例外。

每天自动生成一份跨项目工作报告。Codex 对话、决策和技术探索按项目归档，供日后查阅和继续开发。新功能通过有版本的接口接入。

前端设计

不同设备打开的是同一个个人工作空间。工作台默认回到最近的项目、任务或会话，并用相同的名称、信息层级和状态表达，帮助用户接上上次的工作。

  • 让当前工作先被看见。 首页优先呈现可以继续的工作和需要用户处理的事项。设备、同步、存储和算力细节收进对应页面。只有它们影响当前操作时，才在当前界面说明原因。
  • Windows 主端交付独立的原生窗口。 桌面并排展示列表和详情，iPhone 逐层进入。审批面板保留执行设备、工作目录和实际命令。交互验收覆盖键盘焦点、触控热区、减弱动态效果和 iPhone 安全区。

文案要求

澜汐的界面文案必须有诗意。 封面、欢迎语、页面引言、日报开篇和有引导作用的空状态，都要用简净、有节奏、有画面感的中文，让文字呼应当下的场景。封面正文「白日写到的那一行，暮归时仍等着你」作为语气参考。新增页面和改版都要验收文案。

首页、日报和技术探索用贴合当下情境的古诗原句。参考 poetry-skills 按主题、意象和关键词选句，核对原文、作者和篇名后再使用。首页可借江潮写跨设备接续，日报可借暮色收束一天，技术探索可用登高写视野的展开。 Wscats / poetry-skills

桌面主标题以大号粗宋体整句同排，下方紧接作者与篇名。桌面每到整点从 25 联唐诗中离线轮换，收录王湾《次北固山下》的「潮平两岸阔，风正一帆悬。」。副标题沿用本页封面原文。窗口顶部正中的玻璃滑块依次切换 Codex、Claude Code 和「吉光片羽」。任务工作区的案头列表与对谈并排。

界面位置显示文案交互与含义
首页计数案头、行舟、待你定夺在右侧深蓝毛玻璃卡片中排列为三个等宽栏，用两条细竖线分开。每栏上方为标签，下方为数字。悬停提示和无障碍名称分别说明任务总数、正在运行的任务数和待审批请求数。
任务列表案头诸事搜索框用「寻一件案头事」。没有匹配时写「案头未见这一件，换个词再寻。」。点击任务后自动接入，成功后断开同一客户端的其他接入。
任务对话灯下对谈输入框用「把下一步，写在这里…」。空会话写「灯下尚无来信。写下第一句吧。」
Codex 输入框/model、/permissions在已接入的会话里输入 /，用键盘或鼠标选模型和权限档位。候选值来自当前 Codex，选择适用于该会话的后续轮次。
任务操作执舟、暂泊、续航、扬帆、收帆、移离案头、启卷分别对应接入、暂停、继续、开启和关闭自动推进、移出、在 VS Code 打开项目。扬帆与收帆随当前状态切换。指针进入对谈标题或键盘焦点移入时显现，在原位淡出，正文保持原位。双击对谈标题或聚焦后按 F2 可就地编辑任务名称。
窗口顶部菜单栏澜汐、任务、显示、设置、窗口默认隐藏。指针触及窗口内顶边时淡入，离开后淡出。淡出中返回时从当前透明度接续。展开下拉菜单时顶栏保持可见。居中滑块和封面位置固定。系统关闭动画时即时切换。大模型 API 位于「设置」下。
吉光片羽拾得片羽、待理诸事左侧组名切换列表与右侧标题。写一句即可保存，正文首行作为列表预览。待办点方框打勾，条目留在原位，文字淡成灰蓝。
日报与项目记忆一日手记、项目旧笺日报引言用「今日行过哪一程，且在灯下记一笔。」；项目记忆的搜索框用「寻一段旧谈」，仍按项目和日期查找原文。
技术探索探路札记首次记录前写「把试过的路记下来，回头也有迹可循。」列出实际尝试、结果和未解之处。

任务、随记与待办的自动归组

在顶部「设置」配置外部 OpenAI 兼容 API 的基础地址、模型与密钥。配置后用案头会话标题、项目名，或已保存的随记与待办正文片段，在各自列表中自动选择已有组或新建组。判断不准时沿用原展示。归组发生在后台，仍可直接编辑和保存。密钥由 Windows 当前用户加密保存。

「拾得片羽」和「待理诸事」可以把条目拖到左栏目标组名上。手动归组优先，后续模型判断保留用户的选择。完成状态独立于分组。项目目录、设备调度和执行权限按原记录处理。

需要审批时弹出独立窗口，展示实际命令、工作目录与执行设备，按钮用「允许一次」和「拒绝」。用量、剩余时间和错误提示保留准确数值和原因。毛玻璃材质的早期示例见桌面悬停预览与审批弹窗预览。

视觉与动效

前端动效必须达到 Apple 产品式的交互手感。 以 Emil Kowalski 的 apple-design 为视觉和动效规范。按钮按下时立即反馈，列表到详情的过渡交代两者的空间关系，面板滑动时跟随手指，松手后自然停靠。再次触碰或反向操作时，从当前画面的位置接续。

  • 顶部控件采用扁平毛玻璃。 胶囊底座和选中块使用均匀色调并透出柔化的壁纸，以细圆边和颜色区分状态。键盘焦点顺着胶囊的弧线显示。右侧计数使用小标签与常规字重数字，首页小字比计数标签更醒目。
  • 弹窗与主界面统一。 设置、审批、提示、额度面板及下拉菜单采用澜汐的海蓝背景、文字颜色、圆角和按钮层级。无需离开当前工作区即可返回原来的编辑或对话。
  • 回复自动排版。 「灯下对谈」用 Qt 原生 Markdown 渲染 Codex 与 Claude Code 的回复。标题、列表、表格和引用有清晰层次，代码使用浅蓝衬底与等宽字体，长行随窗口宽度换行。排版在后台完成，消息原文仍用于历史读取与归档。
  • 桌面壁纸离线轮换。 已支持读取 Windows「图片」中「澜汐/macOS」各版本目录的横版和方形 JPG、PNG 原图。有 Mavericks 海浪时从它开始，默认每 30 分钟轮换。竖版留在图库供手机使用。未安装本地图库时使用三张内置背景。
  • 任务列表与对话区使用同一层毛玻璃材质。 两块面板沿用早期预览左侧导航的浅海蓝色调、透明度和模糊程度。各自柔化背后同一张整窗壁纸，浪纹在两块面板间自然衔接。文字与图标清晰渲染，消息气泡和输入框可以用稍浅的衬底提高对比度。
  • 减弱动态效果设置生效时，保留即时反馈与空间提示。 大幅位移和弹性运动切换为短淡入或直接状态变化。键盘操作和触控都能完成同一流程。
  • implement-apple-web-ui 补充网页实现细节。 用于响应式布局、语义颜色、触控区域、键盘焦点和 iPhone 安全区的实现与检查。

设计依据来自《澜汐｜前端设计主导思想》。封面采用 Apple OS X Mavericks 海浪壁纸。 Emil Kowalski 的 Apple DesignApple Web UI 实现参考壁纸档案

总体架构

三台电脑分别连接项目原有的 Git 远程。家里节点保存已确认的交接版本，并协调写入权。桌面、CLI 和手机都以同一个项目标识关联任务，磁盘盘符只保存在各设备的映射里。

层次接口与持久状态
用户入口PyCharm / VS Code 终端运行 Codex CLI。Qt 托盘与 Web 调用同一后台；iPhone 通过经鉴权的 HTTPS 入口查看项目或发起已有控制操作。
本机设备代理复用现有 worker 生命周期，采集文件变更、IDE 实例、CLI 活动和资源能力。本机 SQLite 持久化发送队列、最近确认版本与未完成作业，重启后对账。
中心协调服务在家里运行 FastAPI 和独立的 SQLite。保存项目、设备、快照清单、项目控制权、会话写入租约、作业编号和额度记录。设备凭证和浏览器登录分别鉴权。
项目档案与报告设备侧先记录获准归档的对话和活动，再按项目 ID 补传。获准跨设备的数据汇聚到中心，供每日报告、项目检索和后续会话续接使用。报告和检索入口复用现有客户端。
数据与计算Git 管代码版本，Syncthing 搬运已封存的交接材料，Gitea LFS 存大对象。家庭 worker 按项目环境和输入版本运行作业，回传日志、退出码和输出对象。

协调服务用递增的控制权版本拒绝已过期设备的写入，提交同一作业编号只产生一次执行。操作结果未知时先向执行节点核对。旧设备重新上线后，先保存它的独立变更，再决定能否合并。

开发与运行环境

开发与构建

以 Windows 11、PowerShell、Python 3.10+、Node.js 22+ 为开发基线。仓库的 Web 验证记录使用 Python 3.14 与 Node.js 26.13.1。前端按 package-lock 安装，后端依赖按用途锁定。

仓库当前声明 PySide6 6.12.0、FastAPI 0.163.1、Uvicorn 0.54.0、React 19、TypeScript 5、Vite 6，Windows EXE 沿用 PyInstaller 打包。发布时记录实测 CLI 版本及兼容清单。

日常设备

公司台式机使用基础显示显卡，型号待探测。私人笔记本配 RTX 3050，显存容量和运行时可用量以实测为准。家里台式机同时承担开发、协调与重计算，首次启动探测显卡、驱动、运行环境、内存、磁盘和可用带宽。

iPhone 使用 Safari 访问同一 Web 工作台，可添加到主屏幕。首次配置完成设备配对、项目目录映射、各端 CLI 登录和家庭节点登录启动。

在平时开启 VPN 的条件下联调

分别探测模型服务、Git 远程和家里中心节点的可达性。优先复用已有获准网络。若 VPN 占用了默认路由、DNS 或手机的 VPN 通道，验证可共存的路由，或采用经鉴权的 HTTPS 网关访问家庭服务。iPhone 的日常路径设计为保持现有 VPN 开启，覆盖 Wi-Fi、蜂窝和网络切换后的重连。

各机维护自己的解释器、虚拟环境与驱动。工作区内引用本机绝对路径的配置按设备映射；锁定依赖和可复现的项目设置随代码版本管理。

无感换机与数据一致性

  1. 后台准备。设备代理按项目监听已保存文件，以 Git 基线、暂存版本、工作树版本和允许同步的新文件生成快照。补齐尚未推到远程的必要 Git 对象。缓存、密钥、虚拟环境和未经登记的原始大数据按排除规则处理。
  2. 确认一组可恢复数据。CLI 完成一轮且持久记录稳定时，记录项目 ID、线程 ID、轮次、工作目录映射、代码版本及所需对象哈希。中心核对对象齐备后原子发布版本；工作区随后产生的修改进入下一版。
  3. 另一台提前准备。本机后台预取最近项目，在独立目录校验，再安全更新空闲工作区。IDE 已打开或本地出现新修改时先保留本地状态。两个版本从同一基线安全合并；同一处发生冲突时保存双方内容并提示。
  4. 终端照常启动。首次登记时为受管项目配置终端启动适配。在对应目录输入 codex 时按项目选择已验证的线程 ID，交给真实 CLI 恢复；显式子命令、主动新建会话和未登记目录沿用 CLI 原语义。对话在目标机映射后的工作目录执行。
  5. 中断后恢复。网络离线时记录本地修改。中心不可达时可查看已确认进度，自动写入权等恢复连接后再核对。对执行结果不明的命令先查状态；已经运行的外部终端在原机到达安全点后才转移该线程。

首项技术验证　在两台 Windows 的不同盘符、两个 IDE 的真实终端中，输入同一条日常启动命令，核对原线程 ID、历史轮次、实际工作目录和新回复。编辑器尚未落盘的缓冲区、运行中进程和 GPU 显存不能当作可恢复快照。

大文件与低磁盘

仓库存指针，大文件按需下载工作副本。单主副本所在设备离线时，界面显示可用缓存或等待来源；重要对象按策略在另一台设备保留第二份。调度先从在线且空间充足的节点中选址，预留整次上传所需容量。初始候选阈值为剩余低于 10% 停止分配、低于 5% 进入只读，真机测试后调整。

冷文件迁移按复制、目标哈希校验、事务切换索引、清理旧副本的顺序执行。上传期间固定目标，迁移失败继续从旧副本读取。每个阶段可在重启后重试。

人工优先与夜间审批

控制权按项目判断。 任一设备用 VS Code 或 PyCharm 打开登记项目，立即阻止澜汐发起新的自动操作，释放该项目的控制连接。后台可以继续采集设备状态、封存快照和完成用户从前台发起的计算。远端快照先放入暂存区，避免改写用户正打开的工作树。

事件澜汐的行为
IDE 打开项目通过两个 IDE 的项目打开、关闭事件和心跳报告规范化路径，覆盖多窗口和 VS Code 多根工作区。先撤销自动推进与自动审批权，取消未发送的后台操作；执行中的步骤到可安全停止的位置再释放。
个人版后台审查普通命令白名单限于普通命令审批。移出取消旧接入，暂停和移出在发送前复核。切换后的旧轮次可写入最终回复，通知按批处理。CLI 正常退出遇到断网时保存关闭事件并补发。问题与回归记录
关闭 IDE 或崩溃最后一个相关窗口关闭后核对其余设备、外部 CLI、待处理工具调用和实际进程。确认人工已释放后自动连接，按项目原有设置恢复。心跳中断或失联先核对，避免误抢控制权。
进入睡眠时段按用户本地时区和设定时段生效。项目已启用夜间托管、写入权有效且预算充足时，允许在项目沙箱内读写、构建和测试，并对策略覆盖的当前工具审批自动答复。
超出沙箱或预算项目根目录以外写入、提权、未授权联网、读取凭据及发布操作进入等待。按规范化真实路径检查链接与重解析点，子进程继承沙箱。平台无法落实对应隔离时保留待审批。次日显示动作、依据、结果与文件变更。

已有审批绑定原连接及请求 ID。新版本只审批仍有效的请求，记录项目、设备、时间和规则。用户在夜间打开 IDE、点击暂停或撤回托管，后台立即停止发出新的审批及调度动作。一次夜间工具审批不会替用户决定新的产品需求或扩大任务范围。

硬件感知与家庭计算

交互留在当前 IDE 和 CLI。需要 CUDA 的训练、推理、图像处理等项目命令，以及受本机资源持续限制的可迁移作业，由家里 worker 执行。Codex 通过在线模型服务生成回复；家庭显卡承担项目实际启动的本地计算程序。

当前进度　固定提交、CPU/GPU 路由、Windows 执行端、远程取消和产物校验及续传已通过本机回环验证。按版本安全写回项目、检查点、运行时资源探测和真实设备联调待完成。 执行、取消和下载命令 · 里程碑状态

判断时机决策与动作
运行前从项目已登记的运行配置、解释器、框架探测和历史峰值取得资源需求。需要 GPU 时优先选家里可用且环境匹配的 GPU。公司机只承担已验证能跑的任务；RTX 3050 按实际显存与用户策略作为可行的本地执行端。
运行中按作业采样进度、耗时、显存压力、可用内存、换页、CPU 和磁盘等待。资源不足错误可立即触发重新选址，持续低吞吐需结合历史基线及多个采样窗口判断。高 GPU 利用率本身可能是正常工作。
决定切换比较本机剩余时间与传输、排队和家庭执行时间。中心核对家里在线、资源余量、驱动、依赖和输入版本。可断点任务保存检查点再恢复，允许重复执行的步骤从头重跑，有外部副作用或无安全边界的步骤保留现场。
结果回到终端用项目运行入口或 CLI 可调用的作业适配器提交，保持原命令的退出码、日志和取消语义。输入使用固定快照；输出按哈希回传，在原项目版本仍匹配时落盘。用户在前台发起的作业沿用前台所有权。

验证范围　先接入一个项目真实使用的 GPU 命令和一个 CPU 命令。记录源设备、路由原因、队列等待、传输耗时、执行耗时和结果一致性。家庭 GPU 型号、显存、带宽及切换阈值以设备实测为准。

任务类型与 Codex 用量

项目登记时选择默认类型，单个任务可以覆盖。以下是建议默认策略，预算数值和睡眠时间由设置保存。

类型调度与结束条件
长期项目保留跨天目标和检查点，按每日预算推进。交还给人工时保留待办，夜间仅执行已定义范围内的工作。
短期任务设完成条件、单任务预算和截止时间。完成或预算用尽即停止自动推进，记录交付物。
探索性任务在独立工作区隔离尝试，限制轮次、耗时与预算，保留结论与实验记录，由用户决定是否将成果合入主项目。

台账同时展示账号官方短、长额度窗口及刷新时间，以及按项目和线程累计的可观测 token、轮次与运行时长。每条记录按线程、轮次和事件标识去重。官方未提供的指标标为未知；项目统计用于预算控制，账号共享额度按服务端返回值展示。

到达项目预算后暂停该项目；账号额度耗尽时所有相关任务等待官方刷新。恢复前重新核对人工占用、任务目标、预算和沙箱策略。手机可查看“哪个项目用了多少、为何暂停、何时重查”。

每日工作报告

山光忽西落，池月渐东上。 唐 · 孟浩然 《夏日南亭怀辛大》

澜汐按用户所在时区每天自动生成一份报告，可设置出报时间。桌面工作台和 iPhone 查看同一份内容，可回看历史日期。中心节点离线时补生成，设备晚到的数据合并到原日的报告，并标出更新时间。

报告内容统计口径与证据
今天做了什么按项目列出当天参与的任务、编辑、对话、运行结果和变更。汇总人工操作与 Codex 后台推进，并链接具体任务、会话、提交或验证记录。
每个项目用了多少 token从 CLI 和 App Server 可观测的用量事件汇总输入、输出和总 token。按线程、轮次与用量检查点去重，将累计量换算为增量，设备切换和补传时避免重复计入。来源缺失或项目归属不明时标明覆盖范围。
每个项目花了多少时间显示有可观测证据的人工活跃时长及后台执行时长。以 IDE 前台活动或 CLI 交互划分人工区间，排除长时间闲置，将同一项目跨设备重叠区间合并。后台构建、测试和远程计算单独记录，排队时间可另查。
今日推进与思考列出做成的事、通过的验证、遇到的阻碍和下一步。思考部分归纳对话、笔记和决策记录里实际写下的问题、取舍和理由，每条保留来源。
今日技术探索按问题、尝试、结果、结论和待验证项记录调研与实验，保留失败或无改善的尝试。引用原始会话、实验记录和输出位置。

同一用户、同一本地日期对应一份日报。报告完成时保存所用事件版本，次日补传后可更新并追溯。无法分配给具体项目的用量或时长标为未归类，采集缺口标为未知。

项目长期记忆

每个登记项目有独立档案。按稳定的项目 ID 归集获准保存的 Codex CLI 和工作台对话，目录更名、不同盘符和换机续接都可找到原线程。每轮保存用户消息、Codex 可见回复、时间、设备和可用的产物引用。私密内容按项目规则脱敏或留在原机，公司项目沿用已批准的数据范围。

当前进度　同一 Windows 用户和 Codex 数据目录下，澜汐桌面与 VS Code 终端可接续同一会话。桌面只读合并原生可见消息与实时记录，已用真实 CLI 和 App Server 完成回环验证。跨设备项目归档、补传及长期检索待开发。 本机会话使用说明

扩展接口

同步、任务控制和调度通过稳定的项目 ID 与带版本的事件衔接。事件包含唯一标识、项目、时间、设备、必要的线程或任务标识和类型。首批支持工作活动、对话轮次、用量、任务结果和报告生成，允许事后补录和重算。

扩展位置约定
数据来源为 IDE、CLI、测试结果和项目笔记提供适配入口。新增来源把输出转成统一事件，按项目授权、校验和去重。
后台模块报告、归档、检索和通知通过事件订阅或内部服务接口接入。模块可独立启停、重放和升级，失败可重试。新增字段与历史记录向后兼容。
桌面、Web 和交付渠道使用带版本的 FastAPI 接口查询项目记忆和日报，支持按项目、日期与线程过滤。状态入口可按能力注册，预留后续报告格式、提醒渠道及新的工作台页面。

开发计划与验收

按可独立验证的里程碑交付。优先解决真实终端续接和控制权交接，再增加后台计算与夜间自动化。每阶段保存测试环境、输入、实测结果、失败记录与回滚点。

里程碑交付物与通过条件
一 · 真实 CLI 续接双机、不同盘符和两种 IDE。A 留下已暂存、未暂存及新增文件，B 在终端输入 codex 后继续原线程。核对文件与暂存标记、线程 ID、新一轮实际目录；统计额外手动操作数，正常路径目标为 0。

三 · 手机与大文件在现有 VPN 开启时，用真实 iPhone Safari 从 Wi-Fi、蜂窝查看进度、暂停和处理待审批。实测家庭 LFS 预取、校验失败和中断恢复，验证缺少必需对象时不会误报就绪。
四 · 硬件自动调度公司机发起 GPU 作业，核对家庭设备执行、终端结果与文件校验。笔记本测试本地资源充足、显存不足、家里忙碌和中途掉线。比较本地运行与远程端到端耗时，检查同一作业只交付一次。
五 · 分类、额度与夜间验证三类任务的结束条件、额度去重、超额暂停和到点重查。夜间沙箱内构建通过，越界操作留待审批，用户半夜打开 IDE 后自动审批立即停发，次日可核对全部动作。
六 · 日报与项目记忆用公司台式机、私人笔记本和家里台式机产生至少两个项目的记录，验证 token 去重、人工与后台时长、补传更新、iPhone 查看及项目间档案隔离。逐条核对日报结论和原始会话或实验记录。
