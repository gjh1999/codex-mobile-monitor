# 澜汐 R21 安装、升级与验收

## 在另一台 Windows 电脑使用

1. 将整个 `Lanxi-R21-Portable` 文件夹复制到目标电脑本地可写目录。
2. 双击 `Lanxi-Glass-R21-Portable.exe` 启动，可从系统托盘打开和退出。程序自带 Python 与 Qt。代码同步需要 Git for Windows，终端接续需要本机安装并登录 Codex CLI。
3. 测试通过后，日常使用从托盘「跨机接续」完成配对，选择两台电脑都能访问的同一个私人共享目录，或使用已有的澜汐协调服务。GitHub 账户需能在各机读写自己的项目。 [日常配对说明](PERSONAL_SYNC.md)

## 升级与首次配置

### 在已经用澜汐的电脑升级

先通过系统托盘退出旧澜汐，再打开 R21。若 R21 的 EXE 放在旧版数据旁，会自动导入。如果新版放在新的文件夹，首次启动时选择「选择旧版目录」，选旧版 EXE 所在的文件夹。旧目录保留作备份。

迁移完成后，配置、配对、项目索引、对话记录、随记、待办和本机草稿保存在 `%LOCALAPPDATA%\Lanxi\data`。托盘的「打开用户数据目录」可查看。今后换安装目录也会读回这份数据。项目文件、Codex 原生记忆和会话按原位置使用。

### 选择项目母目录

首次使用时，选存放各个项目的上一级文件夹，例如 `D:\Projects`。澜汐识别 Git 仓库和带常用项目文件的目录，会在 Codex 案头加入可启卷的项目条目，并归拢有对应本机路径的 Codex 会话。选择项目条目可查看分支、记忆位置和发现的记忆文件。项目目录里新建或克隆项目后，后台每约五秒更新一次。托盘的「设置项目母目录」可随时重设。

## 运行验收

双击 `验收.cmd`。脚本会启动独立的测试副本，用临时代码仓库、配置和会话记录验收。终端验收不需要 Python、Codex CLI 或 GitHub 账户，需要 Git for Windows 能从命令行运行。

### 本机自检

直接回车选 **1**。依次模拟源电脑和接收电脑，检查空工作区自动克隆、代码与项目记忆双向更新、全局 `AGENTS.md`、已完成的会话记录，以及 12 MiB 文件未进入接收端工作区或 Git 对象库。

### 两台电脑互测

1. 准备两台电脑都能读写的同一个私人 Windows 网络共享，例如 `\\电脑名\LanxiTests`。测试要通过真实共享目录访问同一套文件。
2. 源电脑双击 `验收.cmd`，选 **2** 并输入共享目录。脚本会创建一组独立测试子目录，显示完整路径，并等待接收电脑回传。
3. 接收电脑双击同一文件，选 **3**，输入源电脑显示的完整测试子目录路径。两边窗口保持打开，直至各自显示「验收通过」。

两种模式都生成 JSON 报告，位置显示在窗口末尾，通常在 `%LOCALAPPDATA%\Lanxi\验收报告`。失败时查看报告中最后一个通过的步骤和错误。跨机模式使用共享目录内的测试 Git 仓库，验证物理机器间访问和应用同步。真实 GitHub 登录与仓库推送权限需在日常配置中另验。共享测试子目录由你保留，方便查看本次结果。

## 终端和澜汐接着同一段对话

从终端切到澜汐时，等当前一轮结束并退出 Codex，再到「案头诸事」点开原会话，接入后就能在「灯下对谈」继续发消息。原终端还占用会话时，澜汐显示已保存的对话并等候写权限。

从澜汐切回终端时，在「案头诸事」右键点原来的 Codex 会话，选「查看会话 ID」，在弹窗点击「复制 ID」。解除澜汐对该会话的接入，再用同一 ID 在终端恢复。也可在 Codex 终端里用 `/status` 查看 ID。

新终端进入同一项目后，`codex resume` 会打开会话选择器。只想继续当前目录最近一次会话，用 `codex resume --last`。同一项目有多个任务时，直接指定会话 ID。

```powershell
codex resume -C "E:\Projects\A" "原会话的 UUID"
```

换电脑时，等澜汐同步项目和已完成的会话记录，再用该电脑的项目路径和同一个 ID 运行上面的命令。验收脚本检查会话记录到达，真实对话续写可用上面的命令亲自确认。 [Codex CLI 命令参考](https://learn.chatgpt.com/docs/developer-commands?surface=cli#codex-resume)
